Property Owners · Landing page

For multifamily property owners

Your property can be your investment in Nimble.

Project Nimble is exploring a property-owner path for qualifying multifamily assets. In the proposed model, an owner receives coins equal to the full property value while retaining one-third ownership of the property.

A full-value coin allocation, with continuing ownership.A $1 million property example pairs 100 million Nimble coins at a $0.01 introductory reference value with one-third continuing property ownership for the contributing owner. Final terms require documentation.

For financial investors

Invest capital. Receive its full value in Nimble coins.

Project Nimble is developing a capital-investor path that pairs a participant’s investment with a coin allocation equal to the full investment value, based on the agreed transaction terms.

Full investment value in coins.A $100,000 illustrative investment would correspond to 10,000,000 coins at a $0.01 introductory reference value. Final allocation and terms must be set in definitive documents.
